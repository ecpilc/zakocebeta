Implementation method

By using "const" constants to lock in fixed values, developers can customize the results returned when a value is greater than or equal to a certain number.

Because cheat software can't modify constants in memory, we used this approach.

Call method

Use the "zakocerun" class to call "const" constant checks

Every 125 milliseconds, it checks the relationship between constants and variables using 'if', and if it's out of expectation, it will return false.
